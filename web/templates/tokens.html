接入指南 （如何让客户端使用本网关）

网关地址

{{.BaseURL}}

三种协议入口（鉴权均用网关令牌）

  • POST /v1/chat/completions — OpenAI Chat（NextChat / LobeChat / 各类 SDK）
  • POST /v1/messages — Anthropic Messages（Claude Code / Cursor / Anthropic SDK）
  • POST /v1/responses — 新版 OpenAI SDK
  • GET /v1/models — 可用模型列表（按当前令牌白名单过滤，只返回该令牌可用的模型）

curl 示例

curl {{.BaseURL}}/v1/chat/completions \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer <你的令牌>" \
  -d '{"model":"<模型名>","messages":[{"role":"user","content":"你好"}],"stream":true}'
